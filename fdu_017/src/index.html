Query Resolution

Answers to common deployment inquiries.

Is GloUI compatible with React / Vue / Angular?

Absolutely. While built on pure HTML/CSS/JS, the modular nature allows you to easily componentize these structures in your preferred framework. The CSS variables map perfectly to styled-components or Tailwind.

How intensive are the blur filters on mobile devices?

We utilize hardware-accelerated `-webkit-backdrop-filter` where available, and gracefully degrade complex layered blurs to semi-transparent solids on lower-end hardware to ensure optimal battery life and framerates.

Can the color palette be adapted to light mode?

Yes. By altering the root CSS variables (specifically `--bg-color`, `--glass-bg`, and `--glass-border`), the entire application themes smoothly into a frosted, clean light mode while retaining the vibrant ambient glows.
