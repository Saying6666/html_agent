## 约束规则（必须全部满足）

1) 浏览器兼容
- 所有使用 `backdrop-filter` 的地方，必须同时写：
  `-webkit-backdrop-filter: ...;`
  `backdrop-filter: ...;`
- 顺序必须是前缀在前、标准属性在后。

2) 可访问性（a11y）
- 每个 `<select>/<input>/<textarea>` 必须有可访问名称
- 纯图标按钮必须有 `aria-label`
- 交互按钮显式加 `type="button"`

3) 样式规范
- 禁止使用 `style=""` 内联样式
- 所有样式写入 `<style>`，CSS 必须内联在 HTML 文件的 style 标签里
- 不要用 Tailwind CDN，代码里不能引用 cdn.tailwindcss.com
- 不使用 React/Vue/Svelte/jQuery 或任何构建步骤
- 特效必须炫酷，动画丰富，视觉冲击力强

4) 输出格式
- 只输出完整 HTML 文件内容
- 直接以 `<!DOCTYPE html>` 开头，以 `</html>` 结尾
- 不要输出解释、markdown code fence
- 不引用本地资源，图片使用远程 URL 或内联 SVG
- 语义化 HTML5
