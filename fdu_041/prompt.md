## Round 1: Role + Design System + Sections

# Landing Page Requirements for Modern Premium Glassmorphism & Glo UI

## Theme
Modern Premium Glassmorphism & Glo UI
Target Audience: High-end SaaS users, Enterprise tech, Web3/AI enthusiasts

## Core Design Directives
- **Glassmorphism:** Use `backdrop-filter: blur(16px)` and semi-transparent backgrounds (`rgba(255, 255, 255, 0.05)`).
- **Conic-Gradient Borders:** Apply rotating conic gradients for borders on cards and buttons.
- **Ambient Blurred Orbs:** Position massive, gently pulsating gradient orbs (blur > 100px) behind the main content.
- **Dark Mode Default:** Deep dark background (e.g., `#050505` to `#0f0f15`).
- **Głow Effects:** Glowing drop shadows on active/hovered elements, neon accents.
- **Micro-interactions:** Magnetic hover effects, satisfying click scales, smooth reveal animations on scroll.
- **Typography:** sleek sans-serif like Inter, Space Grotesk or Plus Jakarta Sans. Gradient text for headings.

## Required Sections (12+)

1. **Ambient Hero Section:**
   - Giant glowing orbs in the background.
   - Large gradient typography 'Experience the Next Era of Intelligence'.
   - Call to Action with a glassmorphism button having a glowing border.
   - Interactive 3D/tilt effect on mouse move.

2. **Logo Marquee / Trusted By:**
   - Infinite scrolling logos of top tech enterprises.
   - Glassmorphism container wrapping the marquee.
   
3. **Value Proposition (The 'Glo' Grid):**
   - 3x3 or 2x2 grid of glass cards.
   - Glowing borders that follow the mouse cursor (hover effect).
   - Icons that emit a soft glow.

4. **Interactive Feature Showcase:**
   - Sticky scroll section.
   - Left side: Glass list of features.
   - Right side: Dynamic glass panel changing content/visuals based on active feature.

5. **Metrics / Data Visualization:**
   - Animated counters (0 to 100M+).
   - Glass cards overlaying an animated gradient background.
   
6. **Detailed Capabilities (Tabs):**
   - A Tab interface with glass styling.
   - Smooth fading transitions between tab panes.

7. **Testimonials Canvas:**
   - Masonry layout of user reviews inside glassmorphic tiles.
   - Subtle parallax on scroll.

8. **Integration Ecosystem:**
   - Web of nodes/icons connected by glowing lines.
   - Center node representing this SaaS, radiating pulses.

9. **Security & Compliance Shield:**
   - A section dedicated to enterprise-grade security.
   - A lock/shield icon with sweeping light reflection.
   
10. **Pricing Tiers (Frost & Neon):**
    - 3 pricing models.

12. **Mega Footer:**

    - Comprehensive grid of links.

## JavaScript Requirements
- Native Intersection Observer for fade-in/up scroll reveals.
- Mouse move listeners for the 'glow following cursor' effect on glass cards.
- Mouse move listeners for subtle parallax on background orbs.
- Number counter animations for the Metrics section.
- Auto-scrolling logic (or pure CSS) for the marquee.
- Interactive Tab switching logic.
- Accordion toggle logic for FAQ.

- No placeholder texts. All copywriting must be real, premium SaaS tone.
- High-performance animations, avoid heavy layout thrashing.
- Fully responsive (flex/grid wrap, fluid typography).
- Accessible contrasts even with glass effects.
