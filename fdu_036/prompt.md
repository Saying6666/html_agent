## Round 1: Role + Design System + Sections

# Modern Premium Glassmorphism & Glo UI Framework

## Overview
This project requires a state-of-the-art landing page featuring a premium glassmorphic visual language, complemented by 'Glo UI' elements—ambient blurred orbs, glowing edges, and sophisticated soft-light aesthetics.

## Design Philosophy
- **Glassmorphism Base:** Extensive use of `backdrop-filter: blur()` to create transparent or frosted glass overlays. Borders should use subtle linear or conic gradients to simulate physical glass edges.
- **Glo UI:** Background environments should feature floating, animated, or ambient blurred orbs (using CSS radial gradients and extreme blur) that shift color or position softly to breathe life into the composition.
- **Premium Typography:** Use high-contrast typography, sans-serif or geometric web fonts (e.g., Inter, Poppins, Roboto).
- **Dark Mode by Default:** The aesthetic works best on deep, dark backgrounds (e.g., #0B0E14, deep blues/purples).

## Animation & Micro-Interactions Details
- **Mouse Tracking Glow:** Implement a JS script where a subtle light follows the cursor within certain glass cards (*card lighting effect*).
- **Scroll Reveals:** Sections should fade and slide in as they appear in the viewport (using Intersection Observer).
- **Magnetic Buttons:** Primary buttons should subtly attract to the mouse cursor on hover.
- **Orb Animation:** Background orbs should continuously, slowly drift and change scale.
