# fdu_032

## Round 1

TITLE: Relay Vault
FORMAT: Modern Premium Glassmorphism & Glo UI, ONE long-scroll single-file \index.html\.

Relay Vault is a command-readiness platform for incident teams, continuity leads, and executive operations.
It helps distributed organizations rehearse high-stakes moments:
- supply disruption
- cyber escalation
- communications drift
- executive brief preparation

Hard constraints (do not negotiate):
- Output: ONE complete self-contained \index.html\ only.
- CSS: inline in ONE \<style>\.
- JS: inline in ONE \<script>\.
- No frameworks: no React, no Vue, no Svelte.
- No external libraries: no GSAP, no jQuery.
- No build step.
- No local assets.
- No external images, no external fonts, no external CSS/JS.
- If visuals are needed, use pure CSS and inline SVG only.
- Responsive and accessible, with reduced-motion support.

Art direction: Modern Premium Glassmorphism & Glo UI.
Imagine an interface from a highly advanced, secure command center in the near future.
Visual language vocabulary must include:
1. Backdrop filter blur (glassmorphism panels everywhere)
2. Soft ambient blurred orbs (glow in the background, morphing behind frosted glass)
3. Conic-gradient borders and glowing neon edges
4. Real micro-interactions (magnetic buttons, glow tracking on hover, satisfying ripples)
5. Dark mode by default, deep blacks/purples/blues with vibrant cyan, magenta, and electric blue accents
6. Sophisticated frosted glass layering and depth
7. Sleek monospace or high-tech geometric sans-serif (system fonts like ui-monospace, SF Mono, Menlo, Courier)

Token system mandate:
- Define a complete design system in CSS \:root\.
- Tokens for glassmorphism:
  - glass-bg (rgba colors)
  - glass-border (rgba gradients)
  - glass-blur (backdrop-filters)
  - glow-accents (various intense colors)
  - typography scale, spacing, z-index, easing, transition speeds

Sections Requirements (12+ Required Sections):
All sections must be populated with REAL, comprehensive operational text. No placeholders (no lorem ipsum).
1. Abstract Hero Glo: Ambient morphing orbs, glass title card, pulsing CTA 'Request Briefing Pack', floating particles.
2. Global Readiness Index: A glowing ticker ticker strip of simulated active threats / status indicators.
3. System Overview (Glass Cards): Three major pillars (Cyber, Logistics, Exec Comms) inside frosted cards with glowing hover borders.
4. Threat Matrix (Interactive Radar): A CSS/SVG radar scanning visual, data points lighting up on hover.
5. Live Scenario Dossier (Scrollytelling): Sticky glass UI on one side, scrolling timeline triggers on the other, illuminating the glass panel.
6. Communication Drift Analysis: A graph or node visualization built with flex/grid/borders showing breakdowns and resolutions.
7. Operating Memo: A side-by-side comparison of Legacy vs Relay Vault using neon gradients and frosted backgrounds.
8. Executive Dashboard Preview: A 3D-like glass panel skew effect showing a mockup UI on hover.
9. Workflow Timeline: A linear vertical or horizontal pipeline showing rehearsal cadence, with nodes that light up sequentially.
10. Proof of Readiness (Metrics): Large glowing number counters with subtle glow drop-shadows.
11. Testimonials (Encrypted Transcripts): Quotes displayed like decrypted secure chat logs inside bordered glass panes.
12. Interactive Decision Checklist: Toggleable switches with satisfying glowing animations and strike-through effects.
13. FAQ (Holographic Accordions): Expanding sections with a sweeping light effect.
14. Final Conversion Terminal: A massive glowing orb behind a dark glass panel, final CTA.
15. Secure Footer: Legal, privacy, and system status links.

Copy Rules:
- Write like a high-tech cybersecurity operative or command central.
- Real, detailed, technical and tactical text.
- No 'lorem ipsum'. Fill out all sections.

Interactive JS Needs:
- Custom cursor (optional, but a glow dot that trails the mouse).
- Intersection Observers for fade-in, translate-up, blur-in.
- Mousemove listeners on glass cards to update '--mouse-x' and '--mouse-y' CSS variables for conic-gradient glowing borders.
- Accordion toggles, Checklist toggles, Dashboard data swaps.
